# Verified Bootstrapping of a Compiler for an Imperative Language

This repository contains Rocq and HOL4 developments of a verified compiler for a small imperative language. The compiler is bootstrapped: it can compile itself inside of the ITP, thus removing the need to extract it.

## Running the Rocq submission

Setup, clean-build, proof-checking, and measurement instructions are in the
[Rocq README](rocq/README.md). Run its commands from the `rocq/` directory.
