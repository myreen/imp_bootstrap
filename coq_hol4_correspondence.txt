Notes
-----
- The functional language parser (parsingScript.sml) is more complete than the Coq
  source-language parser; it covers the full functional language including case
  expressions, let chains, and pattern matching.

- The IMP parser in Coq (Parser.v) uses s-expression syntax; the HOL4 file
  imp_parsingScript.sml contains a separate C-style IMP parser (not a direct
  port), while imp_sexp_parserScript.sml is the faithful s-expression port.

- ASMSyntax.v and ASMToString.v are combined into a single HOL4 file.
  Minor naming differences: Coq 'instr' → HOL4 'inst'; Coq 'StoreRSP' → HOL4 'Store_RSP'.

- ImpSemantics.v uses 'steps_done' (incremented counter); HOL4 uses 'clock'
  (decremented counter) for the same fuel-based termination.

- source_to_impScript.sml contains both definitions and proofs (unlike the Coq
  FpToImpCodegen.v which is definitions only).

- CompilerUtils.v multiplication helpers (mulN, mulnat, etc.) are not ported
  as HOL4 uses built-in arithmetic.
